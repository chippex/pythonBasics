# 🐍 pythonBasics

A collection of beginner-friendly Jupyter notebooks covering the Python fundamentals you need before diving into **Machine Learning and AI**.

Each notebook focuses on one core concept, with runnable examples you can edit and experiment with.

## 📚 Contents

| Notebook | Topic |
| --- | --- |
| [`Tuples.ipynb`](Tuples.ipynb) | Creating, indexing, and unpacking immutable sequences |
| [`Sets.ipynb`](Sets) | Unordered collections of unique items and set operations |
| [`Dictionaries.ipynb`](Dictionaries.ipynb) | Key-value data structures and common dictionary methods |
| [`Functions.ipynb`](Functions.ipynb) | Defining and calling functions, parameters, and return values |
| [`NumPy_formatted.ipynb`](NumPy_formatted.ipynb) | Arrays and numerical computing with NumPy, the foundation of most ML libraries |

## 🚀 Getting Started

### Prerequisites

- Python 3.8 or newer
- Jupyter Notebook or JupyterLab
- NumPy (for the NumPy notebook)

### Installation

```bash
# Clone the repository
git clone https://github.com/chippex/pythonBasics.git
cd pythonBasics

# (Optional) create a virtual environment
python -m venv venv
source venv/bin/activate      # On Windows: venv\Scripts\activate

# Install dependencies
pip install notebook numpy
```

### Run the notebooks

```bash
jupyter notebook
```

Then open any `.ipynb` file from the browser window that appears.

> 💡 **No setup?** Upload any notebook to [Google Colab](https://colab.research.google.com/) and run it in your browser.

## 🧭 Suggested Learning Order

1. **Tuples**
2. **Sets**
3. **Dictionaries**
4. **Functions**
5. **NumPy**
